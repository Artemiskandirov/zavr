# Квесты с Завром — демка экрана

Концепт экрана «Квесты» для приложения Учи.ру: живой 3D-Завр, мини-квесты по предметам, бой 1 на 1, ролик про сундук с яйцами, звук и озвучка.

**Открыть демку:** https://artemiskandirov.github.io/zavr/ (после включения GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root).

Экран «Квесты» из приложения Учи.ру, где зелёный блок «Цель марафона» заменён живой 3D-сценой с Завром.

## Запуск

Открой `index.html` в Chrome, Safari или Firefox. Интернет не нужен.

Озвучку из папки `voice/` браузер надёжно грузит только с локального сервера. Запусти в этой папке

    python3 -m http.server 8000

и открой http://localhost:8000. С телефона в той же Wi-Fi сети: http://<IP компьютера>:8000

## Что внутри

- Тап по Завру: шляпа, пузо, хвост и сундук реагируют по-разному. Свайп вбок раскручивает Завра (до головокружения). Попугай и пушка тоже нажимаются. Кнопка «Сундук» — ролик про 100 яиц.
- Плитки мини-квестов (предметы): тап → короткое задание. Закончил мини-квест — Завр получает −8 HP.
- «Сразиться 1 на 1»: бой в три фазы с таймером, бонус за быстрый ответ, щит-сундук, Завр лечится после двух твоих промахов подряд, комбо, 3 жизни.
- Кнопка с динамиком: звук и озвучка.

## Озвучка

Озвучка уже лежит в `voice/` (24 файла, голос сгенерирован и обработан под пирата). Список реплик с эмоциями: `voice/voice-lines.csv`.
Чтобы заменить голос, положи свой mp3 с тем же именем, например `voice/greet.mp3`.
Если файла нет, реплика показывается субтитром и читается встроенным голосом браузера как заглушка.
Рот Завра двигается ровно столько, сколько длится файл.

## Файлы

- `index.html` — вёрстка, 3D-сцена, логика боя и звуки (Web Audio, без файлов)
- `assets/three.min.js` — three.js 0.149 (MIT)
- `assets/` — шрифт Factor A, иконки предметов из ui-kit-uchi, картинки со скриншотов приложения
- `voice/` — сюда кладутся файлы озвучки
