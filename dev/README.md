# Исходники

- `quests.src.html` — исходник страницы с плейсхолдерами вида `__S_MATH__`; `build_q.py` подставляет ассеты и собирает `index.html`.
- `voice_gen.py` + `voice_tts.py` — генерация озвучки (нейроголос + обработка ffmpeg под пирата, ускорение ×1.2).

Скрипты рассчитаны на рабочую папку, где лежали исходные ассеты; для правок проще редактировать `index.html` в корне.
